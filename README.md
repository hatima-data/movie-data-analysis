# 🎬 Movie Feature & Profit Analysis

An exploratory analysis of film dataset attributes (genre, rating, popularity, runtime) with a primary focus on financial performance (profit_usd).

## 📊 Project Objectives
- Determine which genres deliver the highest financial return on investment.
- Analyze correlations between audience ratings and overall profitability.
- Perform advanced multi-field aggregations and conditional logic operations.
